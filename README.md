# এবিসি কম্পিউটার পস

## অ্যাপ সম্পর্কে

এবিসি কম্পিউটার পস (ABC Computer POS) একটি ক্লাউড-বেসড মাল্টি-টেন্যান্ট হিসাব রক্ষণ সফটওয়্যার। বিক্রয়, খরচ, দেনা-পাওনা ও ব্যবসার হিসাব সহজে পরিচালনা করুন এবং আপনার গুগল অ্যাকাউন্ট দিয়ে সাইন ইন করে ক্লাউডে ডেটা সিঙ্ক করুন।

## ব্যবহার ও ইনস্টল করার নির্দেশিকা

১. আপনার মোবাইলের গুগল ক্রোম (Google Chrome) ব্রাউজারে এই লিংকে প্রবেশ করুন: https://bedesignermonir.github.io/abc-pos/

২. আপনার জিমেইল অ্যাকাউন্ট দিয়ে খুব সহজে লগইন করুন। আপনার ডেটা আপনার অ্যাকাউন্টের অধীনে ক্লাউডে সংরক্ষিত ও সিঙ্ক হবে।

৩. ব্রাউজারের ওপরের থ্রি-ডট (...) মেনু থেকে **“Add to Home Screen”** বা **“Install App”** অপশনে ক্লিক করুন। ব্যস! এটি আপনার ফোনের হোম স্ক্রিনে একটি অ্যাপের মতো ইনস্টল হয়ে যাবে।

আইফোন বা আইপ্যাডে Safari ব্যবহার করলে **Share** মেনু থেকে **“Add to Home Screen”** নির্বাচন করুন।

## Firebase কনফিগারেশন

Firebase Web config অ্যাপের HTML-এ আছে এবং ব্রাউজারে দেখা যাবে—Firebase Web config কোনো server-side secret নয়। নিরাপত্তার জন্য Firebase/Google Cloud Console-এ API key-তে website referrer ও API restrictions দিন এবং Firestore Security Rules ঠিক রাখুন।

GitHub Pages workflow সরাসরি repository root-এর static files deploy করে; কোনো build command বা Firebase Actions secret/variable প্রয়োজন নেই। Repository **Settings → Pages → Build and deployment → Source**-এ **GitHub Actions** নির্বাচন করুন। `main` branch-এ push হলে workflow site deploy করবে.

## অ্যাকাউন্ট অনুমোদন ও Firestore Rules

`clkmonir@gmail.com` মাস্টার অ্যাডমিন হিসেবে স্বয়ংক্রিয়ভাবে অনুমোদিত। অন্য সব অ্যাকাউন্ট প্রথমে অনুমোদনের অপেক্ষায় থাকবে; মাস্টার অ্যাডমিনের Admin Panel থেকে তাদের `Admin` অথবা `Partner/Staff` হিসেবে অনুমোদন করতে হবে।

GitHub Pages কেবল PWA ফাইল প্রকাশ করে, Firestore Security Rules নয়। এই পরিবর্তনের আগে Firebase CLI-তে `abc-pos-webapp` প্রজেক্টে অ্যাডমিন হিসেবে লগইন করে নতুন rules প্রকাশ করুন: `firebase deploy --only firestore:rules --project abc-pos-webapp`। এরপর `main`-এ push করলে GitHub Actions থেকে PWA প্রকাশ হবে।

## সুবিধাসমূহ

- বিক্রয়, খরচ, ক্যাশ/ব্যালেন্স, পাওনাদার এবং ড্যাশবোর্ডের জন্য আলাদা ট্যাব।
- প্রোফাইল মেনু থেকে Firebase সিঙ্কের অবস্থা দেখা ও ম্যানুয়ালি সিঙ্ক করা।
- সেটিংস PIN ছাড়াই খোলা যায়; প্রি-সেট আইটেম, একক কস্ট/বিক্রয়মূল্য এবং খরচের ক্যাটাগরি সাইন-ইন করা অ্যাকাউন্টের ডিভাইসগুলোর মধ্যে সিঙ্ক হয়।
- অ্যাডমিন প্যানেলে নির্বাচিত তারিখের মোট বিক্রি, মোট কস্ট ও নিট লাভ দেখা যায়; পার্টনারের তারিখভিত্তিক হিসাব প্রয়োজনমতো খোলা যায়।
- পাওনাদারকে আংশিক বা সম্পূর্ণ পরিশোধ করলে বকেয়া সঙ্গে সঙ্গে আপডেট হয়ে Firebase-এ সিঙ্ক হয়।
- মাস্টার অ্যাডমিন পার্টনারের Firestore প্রোফাইল ও সংশ্লিষ্ট রেকর্ড মুছতে পারেন; নিশ্চিতকরণ বাক্য আবশ্যক। Firebase Authentication-এর সাইন-ইন পরিচয়টি ব্রাউজার থেকে মোছা যায় না, তবে মুছে দেওয়া প্রোফাইল ছাড়া অ্যাপের পার্টনার অ্যাক্সেস থাকবে না।
- বিক্রয় চালান তৈরি, সম্পাদনা ও প্রিন্ট করা।
- বিক্রয়, খরচ, নগদ টাকা এবং দেনা-পাওনার হিসাব রাখা।
- পণ্য, মূল্য ও ব্যবসার তথ্য পরিচালনা করা।
- WhatsApp-এ চালান শেয়ার করা।
- ইন্টারনেট সংযোগ না থাকলেও অ্যাপ খোলা এবং স্থানীয় ডেটা ব্যবহার করা।
- গুগল অ্যাকাউন্ট দিয়ে সাইন ইন করে একাধিক ডিভাইসে ক্লাউড ডেটা সিঙ্ক করা।
